# Application Shell Specification

## Layout Pattern
- **Sidebar Navigation**: The main navigation is located on the left sidebar. This is optimized for the web/iPad experience used by Sales Agents and Admins.
- **Responsive Behavior**: On mobile devices, the sidebar collapses into a hamburger menu. Note that the core Tenant and Owner experiences are mobile-first apps, while the administrative/agent portal heavily utilizes this sidebar layout on larger screens.
- **Main Content Area**: Fills the remaining screen space to the right of the sidebar.

## Navigation Items
The primary navigation links reflect the product roadmap sections:
- Dashboard
- Hostels
- Tenants
- Financials
- Issues
- Agents & Admin

## User Menu
- Located at the bottom of the sidebar.
- Contains the user's profile picture, name, and access to account settings and logout functionality.
